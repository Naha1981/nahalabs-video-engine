## 🚀 Key Features

- **Multi-Track Timeline Studio:** Interactive canvas video composer with Ken Burns motion physics, real-time voiceover audio playback, synchronized karaoke subtitles, and aspect ratio switcher (`16:9` Widescreen, `9:16` Shorts/Reels/TikTok, `1:1` Square).
- **Brand Brain Intelligence:** Enforces exact brand voice, WPM speech velocity targets, hex design tokens, typography, and compliance blacklists.
- **12+ Vertical Industry Strategies:** High-converting hook formulas, retention pacing curves, and visual metaphors for B2B SaaS, D2C E-commerce, Real Estate, Healthcare, CargoIQ Freight, Hospitality/Dining, FinTech, and more.
- **Pre-Compose Validation Gate:** OpenMontage quality gate verifying speech velocity, scene count boundaries, and compliance blacklists before rendering.
- **Post-Render Self-Review Engine:** Automated 6-point critique scoring hook strength, pacing, optical realism, brand voice, and CTA clarity.
- **Cost Governance & Metering:** Exact per-second render and token accounting with audited 98%+ agency cost savings proof.
- **Client Approvals & Annotations:** Timestamped frame-accurate feedback, multi-role governance gates (G0-G3), and client share links.
- **Universal MCP Gateway (`/api/mcp`):** Standardized Model Context Protocol tool server for Claude Desktop, Cursor, and ChatGPT.
- **HMAC v2 Security Sandbox:** Fail-closed SHA256 signed webhooks for Activepieces, Zapier, and Make syndication.
- **System Health & Render Keep-Alive:** Live infrastructure monitoring, 10-minute ping schedulers, and 24-hour uptime graphs.
